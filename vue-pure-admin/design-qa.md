日期：2026-10-20。范围：原 `/business/assistant` 页面改造，保留推荐 API、寻找条件、资源档案和 Campaign 接线。

## 追加验收：仅大模型推荐

用户进一步要求达人/媒体推荐只能由大模型生成。此节为当前行为；下文图1视觉验收中的8条保存结果和20条即时结果属于之前含规则回退的版本，不能作为模型成功证据。

- 即时生成、保存条件、手动更新及每周任务均要求有效模型；模型关闭、凭证缺失、超时、非法 JSON、非法资源 ID 或缺少有效评分/解释时不生成规则推荐。
- 资源库仍用于候选资格筛选，模型接收真实资源资料，独立选择、评分与解释；不给模型预置的规则匹配分/推荐理由，未选中的候选不补位。
- 保存结果仅展示 `source=ai`、`advice_source=ai` 且资源事实未变化的条目。重新读取保留模型评分和理由，资源事实变化后需重新生成，旧规则缓存与历史规则记录不展示。
- 本地真实模型：模型配置为 OpenAI / gpt-5。保存条件50首次真实调用遇到30秒默认超时，页面显示失败且无规则结果。达人推荐默认等待窗口改为120秒（显式配置的超时仍受尊重），并为达人/媒体使用精简专用提示词后，真实调用成功。
- 即时「生成推荐」真实模型调用返回7位候选，均为 `source=ai`，API成功路径要求 `fallback=false`；刷新页面后7位候选恢复，浏览器警告/错误为空。即时与已保存推荐使用各自的既有候选资格筛选条件，数量无需一致。
- 条件50实际模型选出3条：Nova Gear 90分、Future Lens 86分、Circuit Daily 72分。数据库三条均为 `source=ai`、`advice_source=ai`，其余5条历史规则记录不展示；没有虚构新增资源。
- 当前仅大模型截图：`../docs/qa/creator-media-ai-only-saved-20261020.png`、`../docs/qa/creator-media-ai-only-instant-20261020.png`。
- 新增后端回归覆盖：模型未配置/关闭/失败/非法输出，白名单与重复ID处理，禁止规则候选补位，合作建议缺失时不沿用规则，模型评分持久化，事实变动失效，失败不写入成功运行。
- 本地数据库冒烟测试使用独立临时数据库与测试模型，完成后销毁，不修改开发库的模型设置。原IP模块行为保留。
- 验证通过：Go全量测试、独立数据库冒烟、Vue类型检查、ESLint、Prettier、6条前端测试、生产构建。

3. **色彩与令牌**：白色工作区、`#171717` 主文字、`#e8e8e8` 分隔线、`#d4fb00` 操作与选中态。移除该页继承的背景网格与面板阴影，不修改其他页面导航或品牌。选中、禁用、焦点、加载、错误、空结果有对应状态。
4. **图片与资源**：生产组件只读实际头像和已有关联合作作品。当前已保存测试条件中的 Mock 资源没有头像，因此显示姓名首字母并提供真实内容入口；没有把生成图里的虚构照片、作品或媒体标志写入业务库。原资源档案、平台作品读取及无作品状态正常。
