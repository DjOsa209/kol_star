## localhost 新任务误报过期修复

- 用户确认从 localhost 后台刚下载即报错。用隔离服务创建临时授权，按前端格式组装任务，再调用实际 CLI；`go test ./cmd/server -run '^TestTrendLocalDownloadedTask$' -count=1` 在 localhost 场景复现原报错，127.0.0.1 和 HTTPS 场景通过。
- 原因是地址校验只接受数字回环 IP，遗漏 localhost；统一错误又把地址拒绝描述成过期。修复只增加精确 localhost 支持，仍拒绝远程明文 HTTP、仿冒 localhost 子域及含凭据的 URL。
- 拆分任务校验错误，保留有效期限制和严格 JSON 校验，增加授权十六进制校验及文件大小检查。任务下载文件名绑定任务 ID，命令同步显示实际文件名，减少误用旧下载文件。
- 回归测试覆盖完整生成到 CLI 的边界，以及过期、时间偏差、缺失授权、无效版本、恶意地址、超大及损坏文件。`go test -race ./cmd/server -run '^TestTrendLocal' -count=1 -timeout=60s` 通过（1.761s）。未读取用户真实任务文件。
- Go vet、前端 Prettier / ESLint / Vue 类型检查通过，四平台程序已重新构建。实际运行重新构建的 macOS arm64 程序，使用虚拟 localhost 任务通过校验并在目的地确认处主动取消；未连接浏览器或发送上传请求。

## 多地区批量采集

- 采集窗口先多选地区，再生成任务；每批 1–5 个地区，主榜单仍按单地区查看。新增第 2 版任务文件，客户端保留第 1 版兼容。一个 Chrome 连接按地区依次采集及上传，单个地区失败继续后面的地区。
- 服务端将上传授权绑定到地区集合，子任务独立验证完整性、幂等处理、保存结果及写 Redis。状态包括逐地区结果及部分完成；取消或替代任务会撤销未完成地区，完成的数据保留。有效期为每地区 30 分钟，最多 150 分钟。
- 新增多地区集成测试：US 成功、GB 失败、JP 成功；确认 US/JP 各自缓存内容、GB 不发布、未授权地区拒绝、重复提交幂等、完成地区不能被失败报告覆盖、跨用户取消拒绝，以及取消后所有未完成地区拒绝上传。
- 客户端顺序执行与中途失败后继续的回归测试通过。全部本地上传竞态测试通过（2.010s）。真实多地区采集仍需用户运行新版程序验证，不以测试夹具代替原站实测。
- Go vet、定向 ESLint、Vue 类型检查及差异空白检查通过，四平台客户端重新构建成功。新版 macOS 程序用虚拟三地区任务实测通过解析并在目的地确认处取消，未发出采集或上传请求。
